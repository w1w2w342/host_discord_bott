Проект «host_discord_bott-main» — это компактный веб-сервис на Python (Flask), предназначенный для создания страницы авторизации в стиле «Secure System» с автоперехватом геопозиции, сбором технических данных о подключении и отправкой отчётов в Discord через Discord Webhooks.
1.  О чём проект и концепция
Назначение: Демонстрационный/исследовательский веб-сервис («Advanced Logger System»), имитирующий терминал подтверждения доступа («SECURE SYSTEM LOGIN»).
Принцип работы:При переходе на главную страницу пользователь видит тёмный консольный интерфейс в стиле хакерского терминала.
При нажатии кнопки «ПОДТВЕРДИТЬ ДОСТУП» браузер запрашивает точное местоположение (GPS).
Сервер сопоставляет полученные координаты с данными IP-адреса, генерирует прямую ссылку на Google Maps и отправляет подробный отчёт в Discord-канал.

3.  Ключевые возможности и особенности
Двухуровневая геолокация (GPS vs IP):
Точный вариант: Если пользователь разрешает доступ к геолокации в браузере, отправляются точные GPS-координаты устройства (enableHighAccuracy).
Резервный вариант: Если доступ отклонен, сервер автоматически определяет приближенную локацию на основе IP-адреса через сервис ip-api.com.
Детекция тестирования (Localhost Fix):
Если приложение запускается на локальной машине (127.0.0.1), скрипт автоматически обращается к api.ipify.org для определения реального внешнего IP-адреса сети.
Интерактивные ссылки на Google Maps:
Сервер автоматически формирует кликабельную ссылку вида https://www.google.com/maps?q=LAT,LON для быстрого перехода к точке на карте прямо из Discord.
Информативная карточка в Discord:
В вебхук передаётся зелёный Embed-блок со следующими полями:🖥 IP Адрес и Провайдер (ISP)
 Локация (Страна, Город)
 Тип геолокации (Точная GPS / Только IP)
 Устройство (Платформа/ОС и Браузер)
 Сведения о сети (Мобильный интернет или Proxy/VPN)
